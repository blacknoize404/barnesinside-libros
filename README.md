# barnesinside · libros

PDF de los cursos y compendios de [barnesinside](https://barnesinside.is-a.dev/cursos/).

Cada versión de cada libro es una **release** (`<libro>-v<versión>`) con su PDF y, si lo
tiene, su solucionario. No descargues desde aquí: la ficha de cada libro en la web
siempre apunta a la última versión y conserva el historial.
