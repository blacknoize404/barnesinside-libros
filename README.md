# barnesinside · libros

PDF de los cursos y compendios de [barnesinside](https://barnesinside.is-a.dev/cursos/).

Los PDF están en las **[releases](https://github.com/blacknoize404/barnesinside-libros/releases)** de este repositorio:
una release por versión de cada libro (`<libro>-v<versión>`), con su PDF y, si lo tiene, su
solucionario. Para leer o descargar, mejor la ficha de cada libro en la web: siempre apunta a la
última versión y conserva el historial.
